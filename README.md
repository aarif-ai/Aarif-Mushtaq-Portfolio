# Aarif Mushtaq — Portfolio

Static portfolio site: plain HTML, CSS and a little JavaScript. No framework, no build step.

- `site/` — the public website (the only folder Netlify publishes)
- `content.md` — approved text for every page (source of truth)
- `CLAUDE.md` — rules for Claude Code when working on this repo

Run locally: `python -m http.server 8000 --directory site` and open http://localhost:8000
